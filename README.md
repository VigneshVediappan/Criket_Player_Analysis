# Cricket Player Analysis

## Aim
To analyze cricket player performance using R programming.

## Description
This project analyzes sample player statistics including matches, runs, and wickets. It calculates run average and identifies the highest run scorer and highest wicket taker.

## Technologies Used
- R Programming
- Data Frames
- Basic Statistical Functions

## Features
- Displays player statistics
- Calculates runs per match
- Finds the highest run scorer
- Finds the highest wicket taker
- Calculates average runs

## How to Run
1. Open `10_Cricket_Player_Analysis.R`.
2. Run the program in RStudio or VS Code.
3. View the output in the R console.

## Result
The program successfully analyzes cricket player performance and identifies the leading players.
